# ZAYNE UI — FULL ARCHITECTURE GUIDE
# For Codex: Complete package rebuild from scratch

---

## WHAT THIS IS

Zayne UI is a CSS token-driven component engine for Laravel + Blade.
It is a **Composer package** (`zayne/ui`) that works immediately after install.
No `php artisan zayne:install` required to use components.
No stub copying. No file generation.

The user adds two directives and uses components instantly:

```blade
<head>@zayneStyles</head>
<body>
    <zayne:button variant="solid" color="primary">Save</zayne:button>
    @zayneScripts
</body>
```

---

## CORE PRINCIPLES

- PHP class owns props + variant resolution
- Blade renders structure only — zero logic
- CSS variables drive all theming
- One CSS file. One JS file.
- Alpine.js only for interactive DOM state (Overlay components + root layout)
- All Alpine x-data definitions live in zayne.js — never inline in Blade
- Zero Tailwind dependency
- No base class. No traits. No external variant maps.
- Variant map lives inline inside mount() of each component
- Package-owned components — works on composer install, no publishing required
- Publishing is optional — only needed when user wants to customize

## src/ZayneManager.php — SINGLETON

```php
<?php

namespace Zayne\UI;

use Illuminate\Support\Str;
use Illuminate\View\ComponentAttributeBag;

class ZayneManager
{
    /**
     * Convert a CSS property array into an inline style string.
     * Filters out null and empty values.
     *
     * ['background' => 'red', 'color' => 'white']
     * → "background: red; color: white"
     */
    public function styleString(array $styles): string
    {
        return collect($styles)
            ->filter(fn($value) => $value !== null && $value !== '')
            ->map(fn($value, $key) => "{$key}: {$value}")
            ->implode('; ');
    }

    /**
     * Split an attribute bag into two bags:
     * one containing keys that start with $by, one containing the rest.
     */
    public function splitAttributes(ComponentAttributeBag $attributes, array $by = ['class', 'style'], bool $strict = false): array
    {
        return [
            $strict ? $attributes->only($by) : $attributes->whereStartsWith($by),
            $strict ? $attributes->except($by) : $attributes->whereDoesntStartWith($by),
        ];
    }

    /**
     * Extract named props from the attribute bag.
     * Unescapes HTML entities because Blade auto-escapes attribute values.
     * Also handles kebab-case → camelCase conversion.
     */
    public function forwardedAttributes(ComponentAttributeBag $attributes, array $propKeys): array
    {
        $props = [];
        $unescape = fn($value) => is_string($value) ? htmlspecialchars_decode($value, ENT_QUOTES) : $value;

        foreach ($propKeys as $key) {
            if (isset($attributes[$key])) {
                $props[$key] = $unescape($attributes[$key]);
            } elseif (isset($attributes[Str::kebab($key)])) {
                $props[$key] = $unescape($attributes[Str::kebab($key)]);
            }
        }

        return $props;
    }

    /**
     * Strip a prefix from attribute names and move them into a new bag.
     * Example: 'icon:variant' with prefix 'icon:' → 'variant' in new bag.
     */
    public function attributesAfter(string $prefix, ComponentAttributeBag $attributes, array $default = []): ComponentAttributeBag
    {
        $newAttributes = new ComponentAttributeBag($default);
        $keysToRemove = [];

        foreach ($attributes->getAttributes() as $key => $value) {
            if (str_starts_with($key, $prefix)) {
                $newAttributes[substr($key, strlen($prefix))] = $value;
                $keysToRemove[] = $key;
            }
        }

        foreach ($keysToRemove as $key) {
            unset($attributes[$key]);
        }

        return $newAttributes;
    }
}
```

## src/ZayneServiceProvider.php

```php
<?php

namespace Zayne\UI;

use Illuminate\Foundation\AliasLoader;
use Illuminate\Support\Facades\Blade;
use Illuminate\Support\ServiceProvider;
use Illuminate\View\ComponentAttributeBag;

class ZayneServiceProvider extends ServiceProvider
{
    public function register(): void
    {
        $this->app->singleton(ZayneManager::class);
        $this->app->alias(ZayneManager::class, 'zayne');

        $loader = AliasLoader::getInstance();
        $loader->alias('Zayne', Zayne::class);
    }

    public function boot(): void
    {
        $this->bootComponents();
        $this->bootTagCompiler();
        $this->bootAssetManager();
        $this->bootDirectives();
        $this->bootMacros();
        $this->bootCommands();
    }

    /**
     * Register component namespace + blade view paths.
     * User-published path is registered first so it always wins.
     */
    protected function bootComponents(): void
    {
        // PHP classes — <zayne:button> → Zayne\UI\Components\Button
        Blade::componentNamespace('Zayne\\UI\\Components', 'zayne');

        // User-published Blade views override package views
        if (file_exists(resource_path('views/components/zayne'))) {
            Blade::anonymousComponentPath(
                resource_path('views/components/zayne'),
                'zayne'
            );
        }

        // Package Blade views — fallback
        Blade::anonymousComponentPath(
            __DIR__ . '/../stubs/resources/views/components/zayne',
            'zayne'
        );
    }

    /**
     * Register ZayneTagCompiler as a Blade precompiler.
     * Enables <zayne:button> syntax in all Blade templates.
     */
    protected function bootTagCompiler(): void
    {
        $compiler = new ZayneTagCompiler(
            app('blade.compiler')->getClassComponentAliases(),
            app('blade.compiler')->getClassComponentNamespaces(),
            app('blade.compiler')
        );

        app()->bind('zayne.compiler', fn() => $compiler);

        app('blade.compiler')->precompiler(function ($value) use ($compiler) {
            return $compiler->compile($value);
        });
    }

    /**
     * Boot asset routes and Blade directives.
     */
    protected function bootAssetManager(): void
    {
        ZayneAssetManager::boot();
    }

    /**
     * Register @zayneStyles, @zayneScripts, @zayneAppearance directives.
     */
    protected function bootDirectives(): void
    {
        Blade::directive('zayneStyles', function () {
            return '{!! app(\'zayne\')->renderStyles() !!}';
        });

        Blade::directive('zayneScripts', function () {
            return '{!! app(\'zayne\')->renderScripts() !!}';
        });

        Blade::directive('zayneAppearance', function () {
            return '{!! app(\'zayne\')->renderAppearance() !!}';
        });
    }

    /**
     * Add AttributeBag::pluck() macro.
     * Extracts and removes an attribute in one shot.
     */
    protected function bootMacros(): void
    {
        ComponentAttributeBag::macro('pluck', function ($key, $default = null) {
            $result = $this->get($key);
            unset($this->attributes[$key]);
            return $result ?? $default;
        });
    }

    protected function bootCommands(): void
    {
        if (! $this->app->runningInConsole()) {
            return;
        }

        $this->commands([
            Console\InstallCommand::class,
            Console\PublishCommand::class,
        ]);
    }
}
```

## src/ZayneTagCompiler.php

```php
<?php

namespace Zayne\UI;

use Illuminate\View\Compilers\ComponentTagCompiler;

class ZayneTagCompiler extends ComponentTagCompiler
{
    /**
     * Compile opening tags: <zayne:button ...>
     */
    protected function compileOpeningTags(string $value): string
    {
        $pattern = "/
            <
                \s*
                zayne[\:][\w\-\:\.]* 
                (?<attributes>
                    (?:
                        \s+
                        (?:
                            (?:
                                @(?:class)(\( (?: (?>[^()]+) | (?-1) )* \))
                            )
                            |
                            (?:
                                @(?:style)(\( (?: (?>[^()]+) | (?-1) )* \))
                            )
                            |
                            (?:
                                \{\{\s*\\\$attributes(?:[^}]+?)?\s*\}\}
                            )
                            |
                            (?:
                                [\w\-:.@%]+
                                (
                                    =
                                    (?:
                                        \\\"[^\\\"]*\\\"
                                        |
                                        \'[^\']*\'
                                        |
                                        [^\'\\\"=<>]+
                                    )
                                )?
                            )
                        )
                    )*
                    \s*
                )
                (?<![\/=\-])
            >
        /x";

        return preg_replace_callback($pattern, function (array $matches) {
            $this->boundAttributes = [];
            $component = 'zayne::' . $this->extractComponentName($matches[0]);
            $attributes = $this->getAttributesFromAttributeString($matches['attributes']);
            return $this->componentString($component, $attributes);
        }, $value);
    }

    /**
     * Compile self-closing tags: <zayne:button />
     */
    protected function compileSelfClosingTags(string $value): string
    {
        $pattern = "/
            <
                \s*
                zayne[\:]([\w\-\:\.]*)
                \s*
                (?<attributes>
                    (?:
                        \s+
                        (?:
                            (?:
                                @(?:class)(\( (?: (?>[^()]+) | (?-1) )* \))
                            )
                            |
                            (?:
                                @(?:style)(\( (?: (?>[^()]+) | (?-1) )* \))
                            )
                            |
                            (?:
                                \{\{\s*\\\$attributes(?:[^}]+?)?\s*\}\}
                            )
                            |
                            (?:
                                [\w\-:.@%]+
                                (
                                    =
                                    (?:
                                        \\\"[^\\\"]*\\\"
                                        |
                                        \'[^\']*\'
                                        |
                                        [^\'\\\"=<>]+
                                    )
                                )?
                            )
                        )
                    )*
                    \s*
                )
            \/>
        /x";

        return preg_replace_callback($pattern, function (array $matches) {
            $this->boundAttributes = [];
            $attributes = $this->getAttributesFromAttributeString($matches['attributes']);

            if (isset($attributes['slot'])) {
                $slot = $attributes['slot'];
                unset($attributes['slot']);
                return '@slot(' . $slot . ') '
                    . $this->componentString('zayne::' . $matches[1], $attributes)
                    . "\n@endComponentClass##END-COMPONENT-CLASS##"
                    . ' @endslot';
            }

            return $this->componentString('zayne::' . $matches[1], $attributes)
                . "\n@endComponentClass##END-COMPONENT-CLASS##";
        }, $value);
    }

    /**
     * Compile closing tags: </zayne:button>
     */
    protected function compileClosingTags(string $value): string
    {
        return preg_replace(
            "/<\/\s*zayne[\:][\w\-\:\.]*\s*>/",
            ' @endComponentClass##END-COMPONENT-CLASS##',
            $value
        );
    }

    /**
     * Extract component name from the opening tag match.
     */
    protected function extractComponentName(string $tag): string
    {
        preg_match('/<\s*zayne[\:]([\w\-\:\.]*)/i', $tag, $matches);
        return $matches[1] ?? '';
    }
}
```

## src/ZayneAssetManager.php

```php
<?php

namespace Zayne\UI;

use Illuminate\Http\Request;
use Illuminate\Support\Facades\Route;

class ZayneAssetManager
{
    public static function boot(): void
    {
        $instance = new static;
        $instance->registerRoutes();
    }

    protected function registerRoutes(): void
    {
        Route::get('/zayne/zayne.css', [static::class, 'css']);
        Route::get('/zayne/zayne.js',  [static::class, 'js']);
    }

    public function css(): mixed
    {
        return $this->pretendResponseIsFile(
            __DIR__ . '/../stubs/resources/css/zayne.css',
            'text/css'
        );
    }

    public function js(): mixed
    {
        return $this->pretendResponseIsFile(
            __DIR__ . '/../stubs/resources/js/zayne.js',
            'text/javascript'
        );
    }

    public static function renderStyles(): string
    {
        $version = filemtime(__DIR__ . '/../stubs/resources/css/zayne.css');
        return '<link rel="stylesheet" href="' . url('/zayne/zayne.css?v=' . $version) . '">';
    }

    public static function renderScripts(): string
    {
        $version = filemtime(__DIR__ . '/../stubs/resources/js/zayne.js');
        return '<script src="' . url('/zayne/zayne.js?v=' . $version) . '" defer></script>';
    }

    public static function renderAppearance(): string
    {
        return <<<HTML
<script>
    (function() {
        var saved = localStorage.getItem('zayne.theme') || 'light';
        document.documentElement.className = saved;
    })();
</script>
HTML;
    }

    protected function pretendResponseIsFile(string $file, string $contentType): mixed
    {
        $lastModified = filemtime($file);

        return $this->cachedFileResponse($file, $contentType, $lastModified,
            fn($headers) => response()->file($file, $headers)
        );
    }

    protected function cachedFileResponse(string $filename, string $contentType, int $lastModified, callable $downloadCallback): mixed
    {
        $expires = strtotime('+1 year');
        $cacheControl = 'public, max-age=31536000';

        if ($this->matchesCache($lastModified)) {
            return response('', 304, [
                'Expires'       => $this->httpDate($expires),
                'Cache-Control' => $cacheControl,
            ]);
        }

        return $downloadCallback([
            'Content-Type'  => $contentType,
            'Expires'       => $this->httpDate($expires),
            'Cache-Control' => $cacheControl,
            'Last-Modified' => $this->httpDate($lastModified),
        ]);
    }

    protected function matchesCache(int $lastModified): bool
    {
        $ifModifiedSince = app(Request::class)->header('if-modified-since');
        return $ifModifiedSince !== null && @strtotime($ifModifiedSince) === $lastModified;
    }

    protected function httpDate(int $timestamp): string
    {
        return sprintf('%s GMT', gmdate('D, d M Y H:i:s', $timestamp));
    }
}
```

## src/Console/InstallCommand.php

Simplified. No stub copying. Just wires CSS/JS into the app.

```php
<?php

namespace Zayne\UI\Console;

use Illuminate\Console\Command;
use Illuminate\Filesystem\Filesystem;
use Illuminate\Support\Str;
use Symfony\Component\Console\Attribute\AsCommand;

#[AsCommand(name: 'zayne:install')]
class InstallCommand extends Command
{
    protected $signature = 'zayne:install';
    protected $description = 'Wire ZayneUI directives into your Laravel app.';

    protected Filesystem $files;

    public function __construct(Filesystem $files)
    {
        parent::__construct();
        $this->files = $files;
    }

    public function handle(): int
    {
        $this->components->info('Setting up ZayneUI...');
        $this->newLine();

        $this->ensureAlpineJs();
        $this->registerServiceProvider();

        $this->newLine();
        $this->components->info('ZayneUI is ready.');
        $this->newLine();
        $this->line('  <fg=gray>Add to your layout:</> ');
        $this->line('  <fg=cyan>@zayneStyles</> inside <fg=cyan><head></>');
        $this->line('  <fg=cyan>@zayneScripts</> before <fg=cyan></body></>');
        $this->line('  <fg=cyan>@zayneAppearance</> inside <fg=cyan><head></> (optional, for theme persistence)');
        $this->newLine();
        $this->line('  <fg=gray>Set theme on <html>:</> <fg=cyan>class="light"</> | <fg=cyan>class="dark"</> | <fg=cyan>class="abyss"</>');
        $this->newLine();

        return self::SUCCESS;
    }

    protected function ensureAlpineJs(): void
    {
        $packageJsonPath = base_path('package.json');

        if (! $this->files->exists($packageJsonPath)) {
            $this->components->warn('package.json not found. Install Alpine.js manually: npm install alpinejs');
            return;
        }

        $decoded = json_decode($this->files->get($packageJsonPath), true);
        $all = array_merge($decoded['dependencies'] ?? [], $decoded['devDependencies'] ?? []);

        if (array_key_exists('alpinejs', $all)) {
            $this->components->twoColumnDetail('<fg=green>Found</> Alpine.js', '<fg=gray>alpinejs</>');
            return;
        }

        $this->components->warn('Alpine.js not found in package.json.');
        $this->line('  Run: <fg=cyan>npm install alpinejs</>');
    }

    protected function registerServiceProvider(): void
    {
        $bootstrapPath = base_path('bootstrap/providers.php');

        if (! $this->files->exists($bootstrapPath)) {
            $this->components->warn('bootstrap/providers.php not found. ZayneUI auto-discovers via composer.json.');
            return;
        }

        // Laravel 11+ auto-discovers via composer.json extra.laravel.providers
        // Nothing to register manually
        $this->components->twoColumnDetail(
            '<fg=green>Auto-discovered</> ZayneServiceProvider',
            '<fg=gray>via composer.json</>',
        );
    }
}
```

## src/Console/PublishCommand.php

Lets users copy out specific components to override them.

```php
<?php

namespace Zayne\UI\Console;

use Illuminate\Console\Command;
use Illuminate\Filesystem\Filesystem;
use Symfony\Component\Console\Attribute\AsCommand;

#[AsCommand(name: 'zayne:publish')]
class PublishCommand extends Command
{
    protected $signature = 'zayne:publish
                            {components?* : Component name(s) to publish}
                            {--all : Publish all components}
                            {--force : Overwrite existing files}';

    protected $description = 'Publish Zayne UI components for customization.';

    protected Filesystem $files;

    // All publishable components
    protected array $components = [
        'button', 'badge', 'alert', 'avatar', 'card', 'progress',
        'modal', 'drawer', 'dropdown', 'tooltip', 'popover',
        'input', 'select', 'checkbox', 'toggle',
        'layout/header', 'layout/main', 'layout/sidebar',
        'header/brand', 'header/avatar', 'header/nav',
        'sidebar/brand', 'sidebar/avatar', 'sidebar/label',
        'sidebar/navitem', 'sidebar/navtree', 'sidebar/navtreeitem',
    ];

    public function __construct(Filesystem $files)
    {
        parent::__construct();
        $this->files = $files;
    }

    public function handle(): int
    {
        $targets = $this->option('all')
            ? $this->components
            : ($this->argument('components') ?: $this->askWhichComponent());

        foreach ($targets as $component) {
            $this->publishComponent($component);
        }

        return self::SUCCESS;
    }

    protected function askWhichComponent(): array
    {
        $choice = $this->choice(
            'Which component would you like to publish?',
            $this->components
        );

        return [$choice];
    }

    protected function publishComponent(string $component): void
    {
        $force = $this->option('force');

        // Publish Blade view
        $bladeSrc  = __DIR__ . '/../../stubs/resources/views/components/zayne/' . $component . '.blade.php';
        $bladeDest = resource_path('views/components/zayne/' . $component . '.blade.php');

        if ($this->files->exists($bladeSrc)) {
            if ($this->files->exists($bladeDest) && ! $force) {
                $this->components->twoColumnDetail(
                    "<fg=yellow>Skipped</> {$component}.blade.php",
                    '<fg=gray>use --force to overwrite</>'
                );
            } else {
                $this->files->ensureDirectoryExists(dirname($bladeDest));
                $this->files->copy($bladeSrc, $bladeDest);
                $this->components->twoColumnDetail(
                    "<fg=green>Published</> {$component}.blade.php",
                    '<fg=gray>resources/views/components/zayne/</>'
                );
            }
        }

        // Publish PHP class
        $className = $this->componentToClassName($component);
        $phpSrc    = __DIR__ . '/../Components/' . $className . '.php';
        $phpDest   = app_path('View/Components/Zayne/' . $className . '.php');

        if ($this->files->exists($phpSrc)) {
            if ($this->files->exists($phpDest) && ! $force) {
                $this->components->twoColumnDetail(
                    "<fg=yellow>Skipped</> {$className}.php",
                    '<fg=gray>use --force to overwrite</>'
                );
            } else {
                $this->files->ensureDirectoryExists(dirname($phpDest));
                // Rewrite namespace for user's app
                $contents = str_replace(
                    'namespace Zayne\\UI\\Components',
                    'namespace App\\View\\Components\\Zayne',
                    $this->files->get($phpSrc)
                );
                $this->files->put($phpDest, $contents);
                $this->components->twoColumnDetail(
                    "<fg=green>Published</> {$className}.php",
                    '<fg=gray>app/View/Components/Zayne/</>'
                );
            }
        }
    }

    protected function componentToClassName(string $component): string
    {
        return collect(explode('/', $component))
            ->map(fn($part) => str($part)->studly())
            ->implode('/');
    }
}
```

## PROP RULES

### Props with a Zayne default — never `unset`
```php
public string $background = 'var(--zayne-custom-header)',
public string $shadow     = 'var(--zayne-shadow)',
public string $radius     = 'var(--zayne-radius-field)',
```

### Props off by default — always `'unset'`
```php
public string $border       = 'unset',
public string $bordertop    = 'unset',
public string $borderbottom = 'unset',
public string $borderleft   = 'unset',
public string $borderright  = 'unset',
public string $bordercolor  = 'unset',

public string $margintop    = 'unset',
public string $marginbottom = 'unset',
public string $marginleft   = 'unset',
public string $marginright  = 'unset',
```

Never use PHP `null`. Never use the string `'null'`. Only `'unset'`.

## HARD RULES — CODEX MUST FOLLOW THESE

```
❌  No Tailwind classes anywhere
❌  No hardcoded hex, rgb, or hsl color values in PHP classes
❌  No logic or calculations in Blade
❌  No base class (ZayneComponent) — each component extends Component directly
❌  No traits (HasColorVariants, HasSemanticColors) — variant map inline in mount()
❌  No raw prop values in style= on variant components — always goes through $style
❌  No variants on Layout or Data components
❌  No mount() on Layout or Data components
❌  No $tag prop — href present = <a>, no href = <button> (resolved in Blade)
❌  No @if for slot checks — always use @isset
❌  No inline x-data in Blade — always reference zayne.js by name
❌  No Alpine outside Overlay components or root layout
❌  No 'null' string as prop default — use 'unset'
❌  No PHP null as prop default
❌  No configurable mobile breakpoint — hardcoded 768px in zayne.css section 2
❌  No stub copying in InstallCommand — package works without publishing
❌  No TailwindMerge dependency

✅  Every default prop references zayne.css tokens via var()
✅  Off-by-default props use CSS 'unset' as default value
✅  Layout / Data: props output directly in Blade style=""
✅  Action / Visual / Feed / Form / Overlay: mount() builds $style via Zayne::styleString()
✅  mount() exists only for variant resolution — nothing else
✅  Variant map lives inline inside mount() — no external files
✅  All Alpine x-data definitions live in zayne.js — Blade uses x-data="zayneModal()"
✅  Every component passes $attributes through untouched
✅  Slot names are consistent — $left $right $header $footer $sidebar $iconslot $trigger $trailing
✅  Pseudo-classes :hover :focus-visible :active live in zayne.css section 2
✅  Animations and keyframes live in zayne.css section 3
✅  Mobile breakpoint hardcoded at 768px in zayne.css section 2
✅  One PHP class + one Blade file per component, always
✅  PHP classes live in src/Components/ — package-owned, no install required
✅  Blade views live in stubs/resources/views/components/zayne/
✅  ZayneServiceProvider registers Blade::componentNamespace('Zayne\\UI\\Components', 'zayne')
✅  User-published path registered before package path — user always wins
✅  zayne:publish copies both PHP class + Blade view, rewrites namespace for user
✅  @zayneStyles serves zayne.css via route with version hash
✅  @zayneScripts serves zayne.js via route with version hash
✅  @zayneAppearance injects theme persistence script
```
