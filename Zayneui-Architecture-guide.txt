# ZayneUI Architecture Guide
# Version 2.0
# ============================================================

## WHAT IS ZAYNEUI

ZayneUI is a CSS token-driven Blade component library for Laravel.
- No Tailwind dependency
- No base component class
- No traits
- Works immediately after `composer require zayne/zayneui`
- Zero configuration required
- Alpine.js required as peer dependency (not bundled)

---

## LAYOUT PATTERN

There is NO `<zayne:layout>` wrapper component.
The layout is always `<body class="zaynemainlayout">` as the CSS grid root.

```blade
<!DOCTYPE html>
<html class="dark">
<head>
    @zayneAppearance
    @zayneStyles
    <script defer src="https://cdn.jsdelivr.net/npm/alpinejs@3.x.x/dist/cdn.min.js"></script>
</head>
<body class="zaynemainlayout" x-data="{ mobileOpen: false }">

    <zayne:layout.sidebar>
        <x-slot:header>
            <zayne:layout.sidebar.brand name="MyApp" href="/" />
        </x-slot:header>

        <zayne:layout.sidebar.label title="Main" />
        <zayne:layout.sidebar.navitem href="/dashboard" :active="true">
            <x-slot:lefticon>...</x-slot:lefticon>
            Dashboard
        </zayne:layout.sidebar.navitem>

        <x-slot:footer>
            <zayne:layout.sidebar.avatar name="John Doe" email="john@example.com" />
            <zayne:layout.sidebar.toggle />
        </x-slot:footer>
    </zayne:layout.sidebar>

    <zayne:layout.header>
        <x-slot:right>
            <zayne:button variant="solid" color="primary" size="sm">New</zayne:button>
        </x-slot:right>
    </zayne:layout.header>

    <zayne:layout.main padding="2rem">
        Page content here
    </zayne:layout.main>

    @zayneScripts
</body>
</html>
```

Alpine must load AFTER @zayneScripts so the global functions are defined before Alpine initializes.

## COMPONENT CATEGORIES

### LAYOUT — no variants, props output directly in Blade inline style
- `layout/sidebar`
- `layout/sidebar/brand`
- `layout/sidebar/label`
- `layout/sidebar/navitem`
- `layout/sidebar/navtree`
- `layout/sidebar/navtreeitem`
- `layout/sidebar/avatar`
- `layout/sidebar/toggle`
- `layout/header`
- `layout/header/brand`
- `layout/header/avatar`
- `layout/header/nav`
- `layout/header/nav/item`
- `layout/main`

### ACTION — variant + color + size, buildStyle() via Zayne::styleString()
- `button` — variants: solid, soft, outline, ghost, link, dashed
- `toggle` — variants: solid, soft; colors: primary, success, danger, warning

### FEEDBACK — variant + color, buildStyle() via Zayne::styleString()
- `badge` — variants: solid, soft, outline
- `alert` — variants: solid, soft, outline
- `progress` — color only, optional value indicator

### DATA DISPLAY — variant + color, buildStyle() via Zayne::styleString()
- `avatar` — variants: solid, soft
- `card` — variants: solid, soft, outline

### FORM — color + state, buildStyle() via Zayne::styleString()
- `input`
- `textarea`
- `select`
- `checkbox`
- `radio`
- `range`
- `file`
- `fieldset`

`fieldset` is the wrapper component for labeled form groups:

```blade
<x-zayne.fieldset label="Email" :error="$errors->first('email')">
    <x-zayne.input name="email" wire:model="email" />
</x-zayne.fieldset>
```

### OVERLAY — Alpine-powered open/close, smart auto-positioning
- `modal` — sizes: sm, md, lg, auto
- `drawer` — positions: left, right, top, bottom
- `dropdown` — auto-positions via zaynePosition()
- `tooltip` — auto-positions via zaynePosition()
- `popover` — auto-positions via zaynePosition()

## PHP CLASS RULES

### Layout / Data components
- Extend `Illuminate\View\Component` directly
- No `buildStyle()`, no `mount()`
- Props output directly in Blade with null guards
- Off-by-default props default to PHP `null`
- Always-on props default to CSS token strings

```php
<?php
namespace Zayne\UI\Components\Layout;

use Illuminate\View\Component;
use Illuminate\View\View;

class Sidebar extends Component
{
    public function __construct(
        public string  $background  = 'var(--zayne-custom-sidebar)',
        public string  $padding     = '1rem',
        public string  $gap         = '0.75rem',
        public string  $mode        = 'collapsible',
        public string  $collapse    = 'viewicons',
        public ?string $shadow      = null,
        public ?string $radius      = null,
        public ?string $border      = null,
        public ?string $bordertop   = null,
        public ?string $borderbottom = null,
        public ?string $borderleft  = null,
        public ?string $borderright = null,
        public ?string $bordercolor = null,
        public ?string $margin      = null,
        public ?string $margintop   = null,
        public ?string $marginbottom = null,
        public ?string $marginleft  = null,
        public ?string $marginright = null,
    ) {}

    public function render(): View
    {
        return view('zayne::layout.sidebar');
    }
}
```

### Action / Feedback / Data Display / Form / Overlay components
- Extend `Illuminate\View\Component` directly
- Use `buildStyle()` called from `__construct()`
- Variant map lives inline inside `buildStyle()`
- `$style` string passed to Blade, applied as `style="{{ $style }}"`

```php
<?php
namespace Zayne\UI\Components;

use Illuminate\View\Component;
use Illuminate\View\View;
use Zayne\UI\Zayne;

class Button extends Component
{
    public string $style = '';

    public function __construct(
        public string  $variant    = 'solid',
        public string  $color      = 'primary',
        public string  $size       = 'md',
        public ?string $href       = null,
        public ?string $padding    = null,
        public string  $radius     = 'var(--zayne-radius-field)',
        public ?string $shadow     = null,
        public string  $gap        = 'var(--zayne-gap-button)',
        public ?string $margin     = null,
        public ?string $border     = null,
        public ?string $bordercolor = null,
    ) {
        $this->buildStyle();
    }

    protected function buildStyle(): void
    {
        $variantStyles = [
            'solid' => [
                'primary' => ['background' => 'var(--zayne-color-primary)', 'color' => 'var(--zayne-color-primary-content)'],
                // ... all colors
            ],
            'dashed' => [
                'primary' => ['background' => 'transparent', 'color' => 'var(--zayne-color-primary)', 'border' => '1.5px dashed var(--zayne-color-primary)'],
                // ... all colors
            ],
            // ... all variants
        ];

        $resolved = $variantStyles[$this->variant][$this->color]
            ?? $variantStyles[$this->variant]['base']
            ?? $variantStyles['solid']['primary'];

        $this->style = Zayne::styleString(array_merge([
            'padding'       => $this->padding,
            'border-radius' => $this->radius,
            'gap'           => $this->gap,
            'box-shadow'    => $this->shadow,
            'margin'        => $this->margin,
            'border-width'  => $this->border,
            'border-color'  => $this->bordercolor,
        ], $resolved));
    }

    public function render(): View
    {
        return view('zayne::button');
    }
}
```

## PROP RULES

### Props with a token default — always a CSS var string
```php
public string $background = 'var(--zayne-custom-sidebar)',
public string $padding    = '1rem',
public string $radius     = 'var(--zayne-radius-field)',
public string $gap        = 'var(--zayne-gap-button)',
```

### Props off by default — always PHP null
```php
public ?string $shadow      = null,
public ?string $border      = null,
public ?string $bordertop   = null,
public ?string $borderbottom = null,
public ?string $borderleft  = null,
public ?string $borderright = null,
public ?string $bordercolor = null,
public ?string $margin      = null,
public ?string $margintop   = null,
public ?string $marginbottom = null,
public ?string $marginleft  = null,
public ?string $marginright = null,
```

### In Blade — always null-guard before outputting
```blade
{{ $shadow      ? 'box-shadow: '          . $shadow      . ';' : '' }}
{{ $border      ? 'border-width: '        . $border      . ';' : '' }}
{{ $bordercolor ? 'border-color: '        . $bordercolor . ';' : '' }}
{{ $margin      ? 'margin: '              . $margin      . ';' : '' }}
```

Never output `null` literally into a style attribute.
Never use the string `'unset'` as a default. Use PHP `null`.

## BLADE RULES

### Layout components — inline style, null-guarded
```blade
<aside style="
    background: {{ $background }};
    padding: {{ $padding }};
    {{ $shadow  ? 'box-shadow: '    . $shadow  . ';' : '' }}
    {{ $radius  ? 'border-radius: ' . $radius  . ';' : '' }}
    {{ $margin  ? 'margin: '        . $margin  . ';' : '' }}
    {{ $border  ? 'border-width: '  . $border  . ';' : '' }}
    {{ $bordercolor ? 'border-color: ' . $bordercolor . ';' : '' }}
">
```

### Action / Feedback / Form components — $style string from PHP
```blade
<button class="zayne-button zayne-button--{{ $size }}" style="{{ $style }}">
```

### Tag resolution — always in Blade, never a $tag prop
```blade
@php($tag = $href !== null ? 'a' : 'button')
<{{ $tag }} ...>...</{{ $tag }}>
```

### Slot checks — always @isset, never @if
```blade
@isset($iconslot)
    <span>{{ $iconslot }}</span>
@endisset
```

### Attributes — always pass through untouched
```blade
{{ $attributes->except('class') }}
{{ $attributes }}
```

## COMPONENT SPECS

### Button
```
variants: solid, soft, outline, ghost, link, dashed
colors:   primary, secondary, danger, success, warning, info, base
sizes:    xs, sm, md, lg, xl
slots:    $iconslot, $slot (label), $trailing
props:    href, padding, radius, shadow, gap, margin, border, bordercolor
```

### Toggle
```
variants: solid, soft
colors:   primary, success, danger, warning
props:    checked (bool), color
slots:    $slot (label)
note:     Uses zayne-toggle-track + zayne-toggle-thumb in Blade
          Thumb animates via is-on class
```

### Badge
```
variants: solid, soft, outline
colors:   primary, secondary, danger, success, warning, info, base
sizes:    sm, md, lg
slots:    $slot
```

### Alert
```
variants: solid, soft, outline
colors:   danger, success, warning, info, base
slots:    $slot
props:    padding, radius, shadow, gap, margin, border, bordercolor
```

### Progress
```
colors:   primary, secondary, danger, success, warning, info, base
props:    value (int 0-100), color, showvalue (bool — shows % label)
note:     When showvalue=true, renders value label beside or inside bar
```

### Avatar
```
variants: solid, soft
colors:   primary, secondary, base
sizes:    sm, md, lg, xl
props:    src, alt, radius, shadow, margin, border, bordercolor
note:     src present = show image; no src = show alt initials
```

### Card
```
variants: solid, soft, outline
colors:   primary, secondary, base
props:    padding, radius, shadow, margin, border, bordercolor
slots:    $header, $slot (body), $footer
```

### Input
```
colors:   base, primary, danger, success
props:    type, placeholder, disabled, radius, padding, shadow
note:     Uses zayne-input CSS class for structure
```

### Select
```
colors:   base, primary, danger, success
props:    disabled, radius, padding, shadow
note:     Uses zayne-input zayne-select CSS classes
```

### Checkbox
```
colors:   primary, success, danger, warning
props:    checked (bool), disabled, color
slots:    $slot (label)
note:     Uses zayne-checkbox-box + hidden input + SVG checkmark
```

### Modal
```
sizes:  sm (400px), md (560px), lg (720px), auto (content height)
props:  size, padding, radius, shadow
slots:  $trigger, $slot (content)
note:   Backdrop click closes. Panel click stops propagation.
        Size controls max-width. auto = no fixed height.
```

### Drawer
```
positions: left (default), right, top, bottom
props:     position, width (for left/right), height (for top/bottom), padding, shadow
slots:     $trigger, $slot (content)
note:      Animation direction matches position.
           left/right = translateX, top/bottom = translateY
```

### Dropdown
```
props:  style (passed to panel)
slots:  $trigger, $slot (content)
note:   Auto-positions via zaynePosition() — detects viewport space and flips
        Closes on click outside
```

### Tooltip
```
props:  text (fallback if no slot), style
slots:  $trigger, $slot (optional rich content)
note:   Opens on mouseenter, closes on mouseleave
        Auto-positions via zaynePosition()
```

### Popover
```
props:  style
slots:  $trigger, $slot (content)
note:   Toggle on trigger click, close on outside click
        Auto-positions via zaynePosition()
```

## SIDEBAR COLLAPSE BEHAVIOR

When `html.sidebar-collapsed` class is present:

- **navitem** — icon only visible; on hover shows a tooltip with the item label
- **navtree** — icon only visible; on hover/click shows a dropdown with:
    - Header row: navtree label (non-clickable, styled as section header)
    - Rows: each navtreeitem as a clickable item
- **brand** — click expands the sidebar (calls `Zayne.Sidebar.toggle()`)
- **toggle** — icon only; on hover shows tooltip with label
- **label** — hidden completely (sidebar-label class)
- **sidebar-divider** — shown as horizontal line when collapsed

CSS controls visibility:
```css
html.sidebar-collapsed .sidebar-label { opacity: 0; max-width: 0; pointer-events: none; }
html.sidebar-collapsed .sidebar-divider { opacity: 1; max-height: 2px; }
```

JS controls navtree behavior:
- On collapse: all open navtrees close, state saved
- On expand: previously open navtrees restore

## SMART OVERLAY POSITIONING

`zaynePosition(trigger, panel)` in zayne.js:
- Measures trigger bounding rect and panel dimensions
- Prefers placing panel BELOW trigger
- Flips to ABOVE if not enough space below
- Clamps horizontally to stay within viewport
- Uses `position: fixed` so works inside overflow:hidden containers

Called via `this.$nextTick()` after `open = true` in Alpine data functions.

## JAVASCRIPT — zayne.js

All Alpine data functions defined as global functions (not inside alpine:init):
```js
function zayneModal()    { return { open: false, ... } }
function zayneDrawer()   { return { open: false, ... } }
function zayneDropdown() { return { open: false, toggle() { ... zaynePosition() } } }
function zayneTooltip()  { return { open: false, show() { ... zaynePosition() } } }
function zaynePopover()  { return { open: false, toggle() { ... zaynePosition() } } }
```

Also registered via alpine:init as fallback:
```js
document.addEventListener('alpine:init', () => {
    Alpine.data('zayneModal', zayneModal);
    // ...
});
```

Global namespace:
```js
window.Zayne = { Sidebar, Subbar, Theme };
```

Sidebar API:
```js
Zayne.Sidebar.toggle()    // toggle collapsed state
Zayne.Sidebar.collapse()  // collapse
Zayne.Sidebar.expand()    // expand
Zayne.Sidebar.collapsed   // getter — true/false
Zayne.Sidebar.mode        // getter — 'collapsible' | 'static'
```

Theme API:
```js
Zayne.Theme.set('light' | 'dark' | 'abyss')
Zayne.Theme.toggle()
Zayne.Theme.current
Zayne.Theme.isLight()
Zayne.Theme.isDark()
Zayne.Theme.isAbyss()
```

Subbar API:
```js
Zayne.Subbar.toggle()
Zayne.Subbar.collapse()
Zayne.Subbar.expand()
Zayne.Subbar.collapsed
```

## CSS — zayne.css

Three sections:
1. TOKENS — CSS custom properties for all colors, spacing, radii, shadows
2. STRUCTURE — layout grid, component structural classes, sidebar behavior
3. ANIMATIONS — keyframes and enter/leave animation classes

### Grid
```css
.zaynemainlayout {
    display: grid;
    height: 100dvh;
    width: 100vw;
    overflow: hidden;
    grid-template-areas:
        "sidebar header"
        "sidebar main";
    grid-template-columns: auto 1fr;
    grid-template-rows: auto 1fr;
}
.zaynesidebar { grid-area: sidebar; }
.zayneheader  { grid-area: header; position: relative; z-index: 10; }
.zaynemain    { grid-area: main; overflow-y: auto; }
```

### Sidebar collapse
```css
html:not(.sidebar-ready) * { transition: none !important; }

.sidebar-label {
    transition: opacity var(--layout-transition), max-width var(--layout-transition);
}
html.sidebar-collapsed .sidebar-label {
    opacity: 0; max-width: 0; pointer-events: none;
}
.sidebar-divider { opacity: 0; max-height: 0; transition: opacity 200ms, max-height 200ms; }
html.sidebar-collapsed .sidebar-divider { opacity: 1; max-height: 2px; }
```

### Drawer animations — direction-aware
```css
/* left (default) */
@keyframes zayne-drawer-in-left  { from { transform: translateX(-100%); } to { transform: translateX(0); } }
@keyframes zayne-drawer-in-right { from { transform: translateX(100%);  } to { transform: translateX(0); } }
@keyframes zayne-drawer-in-top   { from { transform: translateY(-100%); } to { transform: translateY(0); } }
@keyframes zayne-drawer-in-bottom{ from { transform: translateY(100%);  } to { transform: translateY(0); } }
```

### Modal sizes
```css
.zayne-modal--sm { width: 400px;  }
.zayne-modal--md { width: 560px;  }
.zayne-modal--lg { width: 720px;  }
.zayne-modal--auto { width: auto; max-height: none; }
```

## THEME TOKENS

Three built-in themes: `.light`, `.dark`, `.abyss`
Applied as class on `<html>`.
Persisted to localStorage via `Zayne.Theme.set()`.
Restored on page load via `@zayneAppearance` directive.

Customizable token groups:
- `--zayne-color-base-*` — page background, content, borders
- `--zayne-color-primary/secondary/danger/success/warning/info` — semantic colors
- `--zayne-custom-sidebar-*` — full sidebar color control
- `--zayne-custom-header` — header background
- `--zayne-radius-*` — border radius tokens
- `--zayne-shadow` — default shadow
- `--sidebar-expanded-w` / `--sidebar-collapsed-w` — sidebar widths
- `--layout-transition` — collapse animation speed

## HARD RULES

```
❌  No Tailwind classes anywhere in the package
❌  No hardcoded hex/rgb/hsl color values in PHP classes
❌  No logic or calculations in Blade
❌  No base class (ZayneComponent) — extend Component directly
❌  No traits — variant map inline in buildStyle()
❌  No raw prop values in style= on variant components — always $style
❌  No variants on Layout components
❌  No buildStyle() on Layout components
❌  No $tag prop — resolve tag in Blade from $href presence
❌  No @if for slot checks — always @isset
❌  No inline x-data strings in Blade — always x-data="zayneModal()"
❌  No Alpine outside Overlay components
❌  No 'unset' string as prop default — use PHP null
❌  No 'null' string as prop default
❌  No configurable mobile breakpoint — hardcoded 768px
❌  No stub copying in InstallCommand — package works without publishing
❌  No TailwindMerge dependency
❌  No zayne:layout wrapper component
❌  No CSS classes for component visual styling — inline style only
    (Exception: structural CSS classes like zayne-button, zayne-button--md are allowed)

✅  Always-on props default to CSS var() token strings
✅  Off-by-default props default to PHP null
✅  Blade null-guards every nullable prop before outputting to style=""
✅  Layout components: props → Blade inline style directly
✅  Action/Feedback/DataDisplay/Form/Overlay: __construct() calls buildStyle()
✅  buildStyle() builds $style via Zayne::styleString() — filters null values
✅  Variant map lives inline inside buildStyle() — no external lookups
✅  All Alpine x-data functions defined as global functions in zayne.js
✅  Registered via alpine:init as fallback
✅  Alpine must load after @zayneScripts
✅  Every component passes $attributes through untouched
✅  Slot names consistent across all components (see SLOT NAMES above)
✅  Pseudo-classes :hover :focus-visible :active in zayne.css section 2
✅  Animations and keyframes in zayne.css section 3
✅  Mobile breakpoint hardcoded at 768px in zayne.css section 2
✅  One PHP class + one Blade file per component
✅  PHP classes in src/Components/ — no install required
✅  Blade views in stubs/resources/views/components/zayne/
✅  ZayneServiceProvider registers Blade::componentNamespace()
✅  User-published path registered before package path — user always wins
✅  @zayneStyles serves zayne.css via versioned route
✅  @zayneScripts serves zayne.js via versioned route
✅  @zayneAppearance injects theme persistence script in <head>
✅  Drawer animations are direction-aware (4 keyframe sets)
✅  Modal has 4 sizes: sm, md, lg, auto
✅  Dropdown/Tooltip/Popover use zaynePosition() for smart viewport-aware placement
✅  Sidebar navitem shows tooltip on hover when collapsed
✅  Sidebar navtree shows dropdown (label + children) when collapsed
✅  Sidebar brand expands sidebar when clicked in collapsed state
✅  Sidebar toggle shows tooltip on hover when collapsed
✅  Progress supports showvalue prop for percent/number display
✅  Button supports dashed variant
✅  body.zaynemainlayout is always the grid root — never a wrapper component
```
